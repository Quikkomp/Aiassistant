# 训练考试

左侧「考试」提供教师发布与学生单次作答，两种入口共用当前登录账号。
当前没有单独的教师角色：登录用户只能发布、编辑自己题库中的考试副本。

## 使用

1. 教师：考试 → 我的题库 → 选择题组 → AI 补全或手动填写答案、解析、评分要点 → 审核 → 发布。
2. 发布后复制分享链接或使用二维码。已发布试卷不可修改，原题库删除不影响考试。
3. 学生登录后扫码、直接打开链接，或在考试 → 加入考试粘贴链接。
4. 每题提交即锁定；批改失败只能重试原答案。刷新可以继续同一次作答。
5. 完成全部题目后交卷，服务端计算成绩，再生成薄弱点讲解。
6. 提交后的详细讲解、追问、类似题与理解状态不改变原题得分。
7. 发布者在已发布考试中点击「成绩分析」，查看完成率、平均分、及格率、最高/最低/中位数、分数分布、逐题正确率、薄弱知识点和学生名单。
   汇总仅包含已完成考试，成绩折算为百分制，及格线为 60 分；进行中的学生不影响平均分与分布。
   「草稿与已发布」使用横向列表，直接显示参与人数、完成人数、已批改作答数与平均分；右侧「展开」在当前列表下显示学生姓名、状态、进度、百分制成绩和完成时间，可刷新或进入完整成绩分析。
8. 关闭考试只阻止新的作答，已开始者可续答。

## 数据与配置

- 考试独立保存在 `exams.sqlite3`，不占学生题库的十组额度。
- 默认总分 100，可修改题目分值；简答与语义评分由 AI 依据审核后的答案和评分要点完成。
- 这是支持逐题反馈的训练模式，不是防作弊的正式考场；一次限制按账号，不能阻止另建账号。
- AI 参考答案需要教师审核，AI 评分也不应替代高风险考核中的人工复核。
- 学生答题前的接口不发送答案、解析、评分要点、老师的文件名或原始知识库。
- 公开部署前配置强随机 `FLASK_SECRET_KEY`；关闭 Flask debug 并使用生产服务及 HTTPS。
- `.env` 的 `PUBLIC_BASE_URL=https://你的站点域名` 决定分享链接与二维码的站点地址。
  未配置时使用当前访问地址，`localhost`/`127.0.0.1` 不能供其他设备访问。
- 二维码由已有 reportlab 依赖本地生成，不上传考试链接到第三方服务。

## 测试

`tests/test_exams.py` 使用真实 Flask 路由、临时 SQLite 和模拟 AI 测试权限、单次作答、并发、批改重试和分数防篡改。
`node tests/exams_browser.cjs` 启动隔离 Flask 测试服务，通过两个浏览器账号验证完整流程和移动端布局。
浏览器脚本的 Python/Playwright 路径是当前 Codex 本机测试环境，不是应用运行依赖。
